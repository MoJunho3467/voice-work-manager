# Backend

현재 이 앱은 서버를 사용하지 않습니다.

일정, 메모, 설정은 Android 기기 내부 SQLite에 저장되고 알림도 기기에서 예약됩니다. 사촌형 한 명이 사용하는 현재 목적에는 별도의 서버를 켜거나 관리할 필요가 없습니다.

다음과 같은 기능이 필요해질 때 이 폴더에 백엔드를 추가합니다.

- 로그인과 사용자 계정
- 여러 휴대폰 간 일정 동기화
- 클라우드 백업 및 복구
- 웹 관리 화면과 데이터 공유
- 서버 기반 AI 또는 음성 처리

백엔드를 실제로 도입하기 전까지 이 폴더에는 실행 코드나 불필요한 의존성을 추가하지 않습니다.

## 현재 알림 기능의 위치

알림 규칙 분석, SQLite 저장, Android 로컬 알림 예약, 완료와 미루기는 모두 `frontend`에서 오프라인으로 처리합니다. 이 기능을 백엔드로 옮기면 서버 연결이 끊겼을 때 알람을 놓칠 수 있으므로 현재 목적에는 적합하지 않습니다.
