# 음성 업무수첩

Expo SDK 57 기반 일정·알림 앱입니다. 서버 없이 SQLite와 로컬 알림을 사용합니다.

## 실행

```bash
npm install
npx expo start --dev-client --clear
```

네이티브 알람 모듈을 추가하거나 수정한 뒤에는 기존 개발자 앱을 새로 빌드해야 합니다.

```bash
npx eas-cli build -p android --profile development
```

## 주요 기능

- 음성 일정 및 음성 메모 입력
- 마지막 인식 결과 후 5초 침묵 시 자동 완료
- 앱 내부 공통 날짜·시간 입력 UI(Android/iOS 동일)
- 실제 알림 날짜·시간을 여러 개 저장하고 개별 편집
- 일반 푸시 알림
- Android 백그라운드 한국어 음성 안내
- Android 잠금화면 전체 알람, 반복 알람음·진동
- 알림 완료 및 10분 미루기
- SQLite 일정·메모 저장과 JSON 백업

## Android 알람 권한

- 앱의 `설정 및 백업 > 강한 알람 권한`에서 정확한 알람과 전체 화면 알람을 모두 허용합니다.
- 최근 앱 목록에서 밀어 닫는 것은 괜찮지만, Android 설정에서 앱을 강제 종료하면 다시 실행하기 전까지 알람이 차단될 수 있습니다.
- Samsung 기기에서는 배터리 사용량을 `제한 없음`으로 설정하는 것이 좋습니다.
- iOS에서는 일반 알림만 사용하며, 백그라운드 음성과 전체 화면 강한 알람은 현재 Android 전용입니다.
# 2026-08 UI/알람 개편

- 첫 화면을 월간 달력 기반의 **일정** 화면으로 변경
- 하단 메뉴를 **일정 / 메모 / 설정**으로 통합
- 날짜별 일정은 개수 제한 없이 반복 추가 가능
- 날짜별 독립 메모 저장, 수정, 삭제, 고정 기능 추가
- 메모 화면은 주간 날짜 선택줄과 월간 날짜 선택 팝업 제공
- 강한 알람의 Foreground Service 제거
- FullScreenIntent로 열린 AlarmActivity에서 반복 소리와 진동을 직접 처리
- 설정 화면은 강한 알람 권한 확인과 백업/복원 중심으로 정리
- 앱 전체 강조색을 보라색 계열로 통일하고 파란색 하드코딩 제거
- 일정 등록/수정 화면을 기본 정보·알림 카드 구조로 전면 개편
- 알림 시점을 상대 표현 대신 실제 날짜와 시간으로 표시
- 날짜별 메모 화면에 음성 메모 입력 복구
- 권한 허용 뒤에도 정확한 알람·전체 화면 알람 상태 카드를 계속 표시
- 강한 알람 화면을 보라색 전체 화면으로 개편
- 잠금 해제 요청을 제거하고 잠금화면 위 표시와 화면 켜기만 사용
